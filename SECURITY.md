# Security Policy

## Supported Versions

Only the latest stable version of YUSEPE-manga receives security updates.

| Version | Supported |
|---------|-----------|
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not create a public GitHub Issue**, as this could expose other users.

Instead, report it by contacting me through one of the following methods:

- GitHub private security advisory (if available)
- Email: mgp.699@gmail.com

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The affected version.
- Any relevant logs, screenshots, or proof of concept.

### Response Process

- I will acknowledge receipt of the report within **5 business days**.
- I will investigate the issue and determine its severity.
- If confirmed, I will work on a fix and publish it in the next security release.
- Reporters who disclose vulnerabilities responsibly will be credited (unless they prefer to remain anonymous).

Thank you for helping keep YUSEPE-manga secure.
